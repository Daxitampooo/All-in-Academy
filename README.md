# All-in Academy

Android app for learning and training No-Limit Texas Hold'em: lessons, drills, games against bots and a ranked mode. No real money: chips have no value and can't be withdrawn.

- `apps/mobile` — the app (Expo / React Native, Android + web preview)
- `docs/ARCHITECTURE.md` — architecture and decisions
- `docs/STATUS.md` — what's done and what's next
- `CLAUDE.md` — project brief

Test builds for Android are on the [Releases](../../releases) page (`preview-*`).
