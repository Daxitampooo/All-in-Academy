# Пожелания владельца по ходу этапа 2a (12.10.2026)

Сообщения владельца дословно и что с ними сделано.

| Пожелание | Решение |
|---|---|
| «у ботов не должно быть написано по какой стратегии они играют» | Описания стиля убраны из приложения. Стили ботов остаются только в документации (docs/requirements/v2-social-bots-academy.md) и в профилях кода. |
| Прозвища тоже выдают стиль («Лимпер», «Колл-станция») | По выбору владельца: до победы видно только имя, прозвище открывается после победы над ботом («Открыто прозвище: «Лимпер»»). |
| «нужно добавить кнопки ставок 3-bet и подобные, может быть отдельную мини вкладочку для них. А так же ползунок, с помощью которого ты можешь контролировать свой сайзинг» | Над кнопками действий — сворачиваемая вкладка «Сайзинг»: название спота (опен-рейз, изо-рейз, 3-бет, сквиз, 4-бет, 5-бет, бет, рейз), кнопки размеров под спот, ползунок с −/+, размер в BB и в процентах банка. Кнопка рейза называет действие: «3-бет до 750». |
| «после завершения игры должна быть еще кнопка Анализ» | Кнопка «Анализ» в итогах матча, при вылете за столом 6-max и при выходе из-за стола. Экран анализа: итог, график по раздачам, VPIP/PFR/3-бет/AF/WTSD/W$SD с пояснениями, все раздачи по улицам, пот-оддсы и эквити с открытыми картами в каждом решении. Оценки «хорошо / неточность / ошибка» и лимит 20 анализов в день — этап 4. |
| «нужно добавить анимацию выкладывания карт на флопе терне и ривере» | Карты борда вылетают от дилера рубашкой вверх и переворачиваются, флоп по одной карте. При олл-ине карты игроков открываются сразу, а борд — по улицам. |
| «придумать какую то механику, после которой засчитывать победу над ботом… Чтобы Сильных ботов реально победить могли только сильные» | По выбору владельца: олл-ин по эквити + серии. Олл-ин до ривера в хедз-ап матче делит банк по шансам рук на момент олл-ина. Серия: Новички и Любители — 1 победа, Регуляры — до 2 побед, Профи, Мастера и секретные — до 3 побед. |
| «я хочу, чтобы анализ проводил бот с озвучкой, у меня есть подписка на ElevenLabs… Чтобы при желании игрок послушал анализ и рекомендации к последующим раздачам» | В плане: озвучка анализа через ElevenLabs после появления сервера (ключ API нельзя хранить в приложении). Фразы ботов можно озвучить заранее и положить в приложение файлами. См. ROADMAP. |
| «хочу пару смешных ботов, например Армен. будет говорить что ему уже давно пора домой и будет говорить с определенным грузинским акцентом» | В плане этапа 2b/2c. Шутки строим на характере и ситуациях («последняя раздача и домой»); подачу акцента обсудить с владельцем: пародия на акцент рискует обидеть игроков и вызвать жалобы в сторе. |
