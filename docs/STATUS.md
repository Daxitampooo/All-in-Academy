## Что сделано в этапе 2a (стол и боты)

- Победа над ботом: серии по лигам (`SERIES_TARGET`), олл-ин по эквити в хедз-апе (`allInSplit` в движке). Прогресс в `bot-progress` v2 с миграцией.

- Движок: +19 тестов (спот, статистика, решения, олл-ин по эквити), всего 79.
- check-locales понимает формы множественного числа (`_one/_few/_many`).

## Как работать в сессии без доступа к npm
1. `scripts/fetch-deps.sh` — скачать `node_modules` для текущего `pnpm-lock.yaml`.
2. Если менял `package.json`: закоммитить и запушить, дождаться workflow `ci` (он закоммитит lockfile и выложит архив), сделать `git pull` и снова `scripts/fetch-deps.sh`.
3. Проверки: `pnpm typecheck`, `pnpm lint`, `pnpm check:locales`.
4. Превью: `cd apps/mobile && CI=1 EXPO_OFFLINE=1 EXPO_PUBLIC_PREVIEW_PRO=1 npx expo export --platform web --output-dir dist`, затем `node scripts/build-preview.mjs <файл>` и публикация файла как артефакта. Если перед этим собирал с `EXPO_PUBLIC_API_URL` (проверка с локальным сервером), добавь `--clear`: кэш Metro запоминает адрес сервера.
5. Логи упавшего CI: аннотации check-run (`gh api repos/<repo>/check-runs/<id>/annotations`).
