## Что сделано в этапе 4 (мои раздачи и анализ)
- Каждая раздача с ботами сохраняется на телефоне (`store/hands.ts`, ключ `hand-history`): история для точного реплея (`historyOf`), результат с учётом олл-ина по эквити, позиция, флаг «на разбор». Хранится до 1000 последних, помеченные — дольше.
- «Мои раздачи» (`/hands`): фильтры по периоду, режиму, позиции и результату (выигрыш, проигрыш, на разбор, с анализом), счётчик анализов. Вход — вкладка «Тренировка» и «Профиль».
- Раздача (`/hand/[id]`): реплеер по шагам и улицам, хедз-ап и 6-max, кнопка «Карты соперников», флаг «на разбор».
- Анализ раздачи — пакет `packages/coach` (`reviewHand`): оценка каждого решения «хорошо / неточность / ошибка», потеря EV в BB, что лучше и почему (40 причин с текстами EN/RU), ссылка на урок Академии (id урока; сами уроки — этап 5). Эквити — против вероятных диапазонов, а не против реальных карт. 11 тестов; на раздачах ботов сильные получают ~95% «хорошо», слабые — много ошибок.
- Лимит: 20 анализов в день, сброс в полночь по времени телефона, повторный просмотр бесплатный; Pro — без лимита. Всё в `src/config/analysis.ts`.
- Из анализа матча — кнопка «Реплеер и разбор» у каждой раздачи. В профиле — раздач сыграно, VPIP и PFR по сохранённым раздачам.

## Что сделано в этапе 3 (оформление и профиль)
- Оформление стола (`/looks`, `src/looks/`): сукно, фон комнаты, рубашка, колода, фишки, неон — 41 предмет. Бесплатные / открываются победами над ботами (временная замена достижений этапа 6) / Pro. Pro пока ни у кого нет (`store/pro.ts`, подписка — этап 7), Pro-предметы можно примерить. Переключатель четырёхцветной колоды.
- Внешний вид стола собирается в `TableLook` (`looks/resolve.ts`) и раздаётся через `LookScope`; `TableFelt`, `PlayingCard`, `BetChip`, `RoomBackdrop` рисуются по нему. Тёмные предметы переключают стол на тёмную палитру и в светлой теме (`PaletteOverride`).
- Заготовка официального стиля рейтинга и турниров: `officialLook(fourColor, leagueColor)`, предпросмотр на экране оформления. Из личных настроек остаётся только четырёхцветная колода.
- Профиль (`store/profile.ts`, хранится на телефоне): ник, «О себе» (140 символов), страна с флагом (список стран EN/RU в `profile/countries.ts`), любимая рука (выбор на сетке 13×13), стиль игры. Экраны `/edit-profile`, `/avatar`; вкладка «Профиль» переделана, статистика — матчи с ботами, победы, обыгранные боты.
- Конструктор аватара: лицо из частей (как у ботов), фон, рамка, обводка, значок; часть открывается победами, часть — Pro. Аватар и ник видны за столом.
- Пакет `packages/moderation`: фильтр мата EN/RU (с обходами вроде «xyй», «х у й», «sh1t»), правила ника, проверка «О себе» (длина, мат, ссылки и контакты). Его же будет использовать сервер. 6 тестов.
- Загрузка своего фото, уникальность ника, настройки приватности — этап 7 (нужен сервер).

## Как работать в сессии без доступа к npm
1. `scripts/fetch-deps.sh` — скачать `node_modules` для текущего `pnpm-lock.yaml`.
2. Если менял `package.json`: закоммитить и запушить, дождаться workflow `ci` (он закоммитит lockfile и выложит архив), сделать `git pull` и снова `scripts/fetch-deps.sh`.
3. Проверки: `pnpm typecheck`, `pnpm lint`, `pnpm check:locales`.
4. Превью: `cd apps/mobile && CI=1 EXPO_OFFLINE=1 npx expo export --platform web --output-dir dist`, затем `node scripts/build-preview.mjs <файл>` и публикация файла как артефакта.
5. Логи упавшего CI: аннотации check-run (`gh api repos/<repo>/check-runs/<id>/annotations`).
