# @pokerall/bots

Bot players for PokerALL. A bot only receives a `PlayerView` from the engine:
public information plus its own hole cards. It can't see other players' cards
or the deck.

- `strength` — preflop strength table (equity of all 169 starting hands against
  a random hand, generated by `pnpm gen:preflop`), draws and pairs, fast Monte
  Carlo equity.
- `brain` — one decision function driven by a style profile (`BotProfile`):
  ranges, aggression, bluffing, calling tendency, love of pairs and draws,
  precision, panic folds. Position-aware profiles widen ranges late and short-handed.
- `novices` — league "Novices" (100–600).
- `simulate` — bot-vs-bot tables and heads-up matches for tests and calibration.

Cheating training bots (a rigged deck, seeing all cards) are deliberately **not**
here: they live in the mobile app's offline training module, so multiplayer code
can never use them.
